# Hi, I'm JockOfCode

I'm a Ruby developer. In my spare time I've been playing with
[Spinel](https://github.com/matz/spinel), an ahead-of-time Ruby-to-C
compiler — mostly game demos and tooling built around it.

## Spinel SDL games

A running collection of small, self-contained games and sandboxes built
with [`sdl`](https://github.com/jockofcode/sdl), a set of SDL3 bindings
for Spinel — each one written to exercise a different corner of the
bindings (physics, text rendering, mouse/wheel input, throughput, sockets):

- [`tower_defense`](https://github.com/jockofcode/tower_defense) — "Bastion Line", grid-based tower defense
- [`pinball`](https://github.com/jockofcode/pinball) — "Stardrift Pinball", flippers, bumpers, a real plunger
- [`click_chess`](https://github.com/jockofcode/click_chess) — full legal chess, mouse-driven
- [`terminal_of_the_old_gods`](https://github.com/jockofcode/terminal_of_the_old_gods) — glyph-only roguelike
- [`vector_blaster_2000`](https://github.com/jockofcode/vector_blaster_2000) — Asteroids-style outline shooter
- [`net_pong`](https://github.com/jockofcode/net_pong) — Pong over raw UDP sockets
- ...and [more](https://github.com/jockofcode?tab=repositories&q=&type=&language=ruby&sort=)

## Libraries

- [`sdl`](https://github.com/jockofcode/sdl) — SDL bindings for Spinel
- [`sdl_ui`](https://github.com/jockofcode/sdl_ui) — immediate-mode UI on top of `sdl`, imgui-inspired
- [`ncurses`](https://github.com/jockofcode/ncurses) — ncurses bindings for Spinel
- [`app_bundler`](https://github.com/jockofcode/app_bundler) — packages a compiled Spinel binary into a real macOS `.app`
- [`asdf-spinel`](https://github.com/jockofcode/asdf-spinel) — asdf plugin for installing Spinel
